# WALL STREET: Rise of the Trader

Полноценный браузерный симулятор финансового рынка и трейдинга. Только виртуальные деньги — никаких реальных платежей.

## Суть игры

Вы начинаете начинающим трейдером и строите финансовую империю: покупаете и продаёте акции, криптовалюты, драгметаллы и валюты, следите за новостями, выполняете задания, открываете достижения, кладёте деньги на депозит, берёте кредиты и растите по карьерной лестнице от «Новичка» до «Легенды Уолл-стрит».

## Версия 2 — единая карьера

- Старт с $10 000 виртуальных денег, постепенное развитие и открытие возможностей.
- Песочница и выживание скрыты из интерфейса; старые данные этих режимов не удаляются и не смешиваются с карьерой.
- Интерактивная академия из шести шагов и трёх вопросов, с пропуском и повтором через кнопку «?».
- Иконки всех 23 активов: локальные SVG, включая стилизованные символы и тикеры; интернет не требуется.
- После продажи открывается полноэкранный отчёт. Повторно его можно открыть в истории продаж. На главной и в портфеле доступны отчёты об изменении капитала и открытых позициях.
- Ролик на 4 секунды создаётся через Canvas/MediaRecorder, если браузер поддерживает запись; есть предварительный просмотр и экспорт файла. На некоторых Android WebView экспорт может быть недоступен, тогда используйте запись экрана.
- Результат продажи в новом отчёте учитывает комиссию продажи, но не комиссию покупки (исходный движок хранит среднюю цену без неё). Открытые позиции показаны до комиссий. Изменение капитала включает награды, проценты и иные поступления.

## Управление

Всё управление мышью/касанием: вкладки «Главная / Биржа / Портфель / Новости / Карьера / Банк», кнопки «Купить/Продать» на карточке актива. График: колесо — масштаб, перетаскивание — сдвиг. Кнопки ⏸ и 🔊 — пауза времени и звук.

## Как запустить

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Основные системы

- **Рыночный движок**: геометрическое броуновское движение по игровой минуте (1 тик ≈ 0.9 с), общерыночный фактор, скрытые режимы рынка (спокойствие/бычий/медвежий/кризис), случайные скачки, индивидуальная волатильность и дрифт каждого актива, посевная годовая история.
- **Новости и события**: генератор новостей по шаблонам с реальным влиянием на цены (эффекты с затуханием), экономический календарь с наступающими событиями (решения ФРС, отчётности компаний).
- **Торговля**: покупка/продажа с комиссией 0.1%, история сделок, избранное, сравнение до 3 активов, свечные графики с 9 таймфреймами (1м–1год), зумом и кроссхейром.
- **Портфель**: позиции со средней ценой, нереализованный P&L, круговая диаграмма распределения.
- **Карьера**: 8 уровней, опыт за сделки/задания/достижения, карьерные и ежедневные задания, 12 достижений.
- **Банк**: депозит (6–10% годовых, начисление каждый игровой день), кредиты (14% годовых, лимит от капитала и уровня), магазин улучшений.
- **Дивиденды**: дивидендные акции выплачивают доход каждые 10 игровых дней.
- **Сохранение**: весь прогресс автоматически сохраняется в localStorage. Ключ существующего карьерного сохранения не изменён.

## Технологии

React 19 + TypeScript + Vite, zustand для состояния, canvas-графики (свечи, линии, donut), Web Audio API для синтезированных звуков, детерминированный ГПСЧ (mulberry32).
