WALL STREET: Rise of the Trader — обновление 2

1. Распакуйте этот ZIP. Внутри папка app с полными исходниками, а не готовый APK.
2. В существующем GitHub-репозитории rswapp откройте Code → Add file → Upload files.
3. Перетащите целиком распакованную папку app (не ZIP) в поле загрузки на уровне корня репозитория. Проверьте пути app/src/components/ResultScreen.tsx и app/src/components/Tutorial.tsx. Подтвердите Commit changes.
4. Если существующий workflow APK уже работает, менять его не нужно. Резервная копия лежит в .github/workflows/build-apk.yml.
5. Actions → последний запуск → после зелёной галочки Artifacts → WALL_STREET. Распакуйте архив и отправьте APK на Android.
6. Для браузерного запуска: cd app, npm install, npm run dev. Для проверки: npm run build, npx playwright install chromium, npm run verify.

Проверено: синтаксис 26 TS/TSX файлов и локальные импорты. Полноценный build и браузерные тесты не выполнены: среда не разрешает скачивание зависимостей npm. GitHub Actions должен выполнить сборку. Экспорт короткого видео зависит от поддержки Canvas/MediaRecorder в браузере или Android WebView; при отсутствии поддержки есть подсказка использовать запись экрана.
Старый ключ сохранения карьеры не изменён. Сохранения иных режимов не удаляются, но недоступны в новом меню. Если Android не принимает новую сборку из-за другой подписи APK, не удаляйте старое приложение, пока не решите вопрос с сохранением прогресса.
